# Customer & Transaction Management System

A Python-based customer and transaction management application designed to help small businesses manage customer records, sales transactions, reporting, and data storage through CSV files.

---

## 🎯 Key Skills Demonstrated

* Python Programming
* Object-Oriented Programming (OOP)
* Data Structures (Lists & Dictionaries)
* CSV File Handling
* CRUD Operations
* Data Visualization (Matplotlib)
* Data Analysis
* Software Design Principles

---

## 📌 Project Overview

This project provides a command-line system for managing customers and sales transactions. Users can add, search, update, and delete customer and transaction records while maintaining data persistence through CSV files.

The application also includes reporting and visualization features to analyze transaction trends and customer activity.

---

## 🚀 Features

### Customer Management

* Add new customers
* Search customers
* Delete customer records
* View customer information

### Transaction Management

* Add sales transactions
* Search transactions
* Delete transaction records
* View transaction history

### Data Persistence

* Load customer records from CSV files
* Save customer records to CSV files
* Load transaction records from CSV files
* Save transaction records to CSV files

### Reporting & Analytics

* Monthly sales analysis
* Transaction trend analysis
* Customer-specific sales reports
* Postcode-based sales reports
* Data visualization using Matplotlib
